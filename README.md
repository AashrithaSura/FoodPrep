🍔 Food Prep App

A full-stack Food Ordering & Management web application where users can browse food items, place orders, rate dishes, and manage their profiles, while admins can manage menu items and orders efficiently.

🚀 Features
👤 User Features
Browse food menu with images & details
Add/remove items from cart
Place orders
Rate food items (personal rating system)
View order history
User profile management (including profile picture upload)
Promo codes & offers support
🛠️ Admin Features
Add / update / delete food items
Manage orders
View user feedback & ratings
Control menu availability
🎯 Additional Features
Role-based authentication (User / Admin)
JWT-based login system
Mobile-friendly UI (Amazon-style navigation)
Toast notifications for updates & promotions
Cloudinary image upload integration
Settings page with notification toggles & offers

Frontend:

Backend:
